# Javascript 30

Javascript 30 was created by **Wes Bos** which includes 30 vanilla JS projects for Beginner to Intermediate developers and designers who want to become comfortable with both JavaScript fundamentals and working in the DOM without a library. This challenge helps you develop some fun projects as well as strengthen your basic fundamentals of Javascript.

If you want to participate in this challenge you can visit his website at [Javscript 30](https://javascript30.com/).

All the projects have been made using HTML, Tailwind CSS, Javascript, and Vite as the package bundler.
